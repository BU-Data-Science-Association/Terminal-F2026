Jacky is asking for directions from CDS 164 to Professor Wobbes's office. 
He has a really bad memory so he needs you to write it down as a bash script composed of one of several “cd” commands and to bring it to him back in CDS 164
Write the script in this directory, then use cp to make a copy of it all the way down to CDS 164, then take the elevator down and run the script to make sure it works and come back up here to the 14th floor!

---
bash scripts are basically just conjunctions of terminal commands that you can run at once.
usually they have the .sh extension, although like all files they don't actually need a file extension
run a bash script in the current directory with ./<filename>
